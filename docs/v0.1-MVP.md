# v0.1 copilot

Local checks decide pass or fail. Luna is optional and only for generate requests the code cannot build itself.

## What you can run

Audit a print file. This does not call a model.

`python -m extrude.copilot audit tests/fixtures/parse/enclosure.scad --filament PETG`

Audit a KiCad netlist the same way, with the `.net` path.

Generate a circuit the harness already knows, with no model:

`python -m extrude.copilot generate "12V to 3.3V divider" --offline`

Repair a small OpenSCAD hole in place:

`python -m extrude.copilot audit tests/fixtures/parse/enclosure.scad --filament PETG --repair`

The HTTP door is `POST /v1/copilot`. The older `POST /v1/design` door still works.

## What the reply means

`violations` are blocking. `warnings` are not a pass and not a fail. A FeatureScript operation this subset does not read, such as a fillet, is a warning. A cylinder or hole the parser could not measure is a violation, and that file is not checked. `locked` lists holes and walls the repair was not allowed to change. A missing file, a failed audit, and a needs-info reply exit as an error from the command line.

## Money

Checkers, SQLite, and ngspice are free. Set `EXTRUDE_SPEND_CAP_USD` (default 5). The cap is checked before every Luna call, including a retry in the same run. Passive circuits never call the model. `--offline` refuses a generate request that would need Luna.

Set `EXTRUDE_MEMORY_DB` to a sqlite file. A failed audit is stored there, and the next audit of that same file returns it in `constraints`. The spend cap reads that same file.

## Capacitor audit

A KiCad netlist can carry the capacitor fields the derating check needs: `Dielectric`, `Manufacturer`, `Series`, `Case`, `VoltageRating`, `BiasV`, and `CMin`. A class-II part whose use-value is under `CMin` fails the audit, and the reply includes the measured farads.

## What this is not

A motherboard score, a fab package, KiCad DRC, or a weight update. Those stay later. New checks plug into `extrude/harness/registry.py`. The copilot URL stays.
