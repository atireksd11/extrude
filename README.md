# Extrude

Extrude is a local helper for simple power circuits. A model may suggest a design. The checks decide whether it meets a frozen requirement card.

The long architecture write-up is [docs/architecture/hardware-ai-master-blueprint.md](docs/architecture/hardware-ai-master-blueprint.md).

Start with the one-page room map: [docs/MAP.md](docs/MAP.md).

This build stays private until the practice-set bar in [docs/GROUND-RULES.md](docs/GROUND-RULES.md) is met: Luna at least 40%, and Astra at least 73%, each on two full runs.
