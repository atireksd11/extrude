# Robotic gripper demo

This is an intentionally small hardware project for trying Project Atlas. The firmware drives a motor through pin 12. The exported KiCad netlist connects the MOTOR net to U1 pin 12. Use **Make a demo change** inside Atlas to switch the firmware pin between 12 and 13 and see a real pin-map failure and change impact.

The matching OpenSCAD source and STL describe a simple two-part jaw so the in-app viewer can rotate it.
